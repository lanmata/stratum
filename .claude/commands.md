# Commands (Slash Commands)

| Command | Agent | Trigger |
|---------|-------|---------|
| `/implement-feature` | developer | New entity end-to-end (constants, model, service, BFF, component, route) |
| `/implement-component` | developer | New standalone Angular component |
| `/add-route` | developer | New lazy-loaded Angular route |
| `/add-bff-endpoint` | api-designer | New Express BFF proxy route + Angular API constant |
| `/fix-bug` | developer | Bug report in component, service, BFF, or interceptor |
| `/fix-typescript-errors` | developer | TypeScript strict-mode errors blocking build or type-check |
| `/write-unit-tests` | test-writer | New code or missing test coverage |
| `/review-code` | code-reviewer | PR review or post-implementation check |
| `/security-audit` | security-reviewer | Pre-release, auth change, or dependency update |
| `/full-feature-delivery` | orchestrator | Complex multi-layer feature requiring all agents |
