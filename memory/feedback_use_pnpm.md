Always use `pnpm` instead of `npm` for all package manager commands in this project.

**Why:** User explicitly corrected npm usage — this project uses pnpm.

**How to apply:** Replace `npm run`, `npm install`, `npm test`, etc. with `pnpm run`, `pnpm install`, `pnpm test`, etc. in all shell commands and tool references.
